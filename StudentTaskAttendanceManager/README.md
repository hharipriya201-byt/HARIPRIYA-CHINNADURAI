# Student Task & Attendance Manager

A responsive student dashboard built with HTML, CSS and JavaScript.

## Features
- Add and manage subjects
- Track attended and total classes
- Automatic attendance percentage
- Low-attendance warning
- Add, complete and delete tasks
- Dashboard statistics
- Data persistence using LocalStorage
- Responsive design

## Technologies
- HTML5
- CSS3
- JavaScript (ES6)
- Browser LocalStorage

## Run
Open `index.html` in any modern browser. No installation or backend is required.
